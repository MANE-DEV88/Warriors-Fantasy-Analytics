  2. Use an OAuth callback and token storage on a private backend, not in GitHub Pages.
  3. Fetch league settings, teams, weekly matchup totals, rosters, and eligible free agents where supported.
  4. Normalize Yahoo category identifiers into this dashboard's JSON format.
  5. Publish read-only weekly summaries to the frontend; protect any private league information.

Version 5: Midweek and league-history import fields

Optional top-level snapshots entries contain week, asOf (YYYY-MM-DD), and a complete teams array using the same eleven counting / shooting fields as weekly totals. Each snapshot represents cumulative weekly statistics through the end of that day. The War Room automatically selects the latest snapshot no newer than yesterday.

Optional top-level matchups entries contain week, home and away, corresponding to the two scheduled teams. This powers completed-week league W-L-T in the history tab. Without it, the site shows all-play statistics but does not invent official W-L-T records.

Privacy: Imported JSON stays in the current browser session; this page does not upload your JSON to a remote server. Avoid putting real league data in the public GitHub repository.
